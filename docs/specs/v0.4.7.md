Started 30 Oct 2026. App and integration (0.4.7; 0.4.6 is the last released integration).
Draft: items get added here, and nothing is built until Michael says to build.

## Rules (as for v0.4.6)

- Pull first; work on `claude/ios-home-assistant-app-73ao17`; commit in small steps and push;
  Michael merges from GitHub.
- Build exactly what the list says; if something can't work as written, stop and ask.
- Bump `custom_components/bedtime_bridge/manifest.json` to 0.4.7 if the integration changes. A
  test for every item (pytest `tests/ha`, `BedtimeBridgeTests`); run both, and build and run on
  the iPhone before an item is done.
- Don't change the live Home Assistant: HA-side changes go in `docs/ha-handoffs-v0.4.7.md`, phone
  shortcuts in `docs/shortcuts.md` (signed shortcut files stay out of git; copies to install go
  in Desktop → Shortcuts → to import → <date>). Update `docs/setup.md` with any new step, and the
  README (and its pictures) where a screen changes.
- Protected actions use the bottom-bar slide-and-hold.
