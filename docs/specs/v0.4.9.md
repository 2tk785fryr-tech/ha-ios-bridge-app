## Items

1. **Naps and bedtime pending.** Found by the Home Assistant chat while reviewing the 0.4.8
   blueprint edit: the integration's automatic report "in bed 10 minutes with bedtime pending and
   no RUN_BEDTIME" doesn't check for a nap, so a nap taken while tomorrow's alarms are set files a
   false report.
   - **Checked (read-only), and it's wider than the report:** `bedtime_pending` (v0.4.8 item 1)
     ignores naps too. It's on from setting alarms until bedtime runs or 2 h before the first
     alarm, so a nap in that time (set tomorrow's alarms in the afternoon, then nap) has it on.
     With the 0.4.8 blueprint edit, the Bedtime Nudge then treats getting into bed for the nap as
     bedtime, at any hour: it would nudge and send RUN_BEDTIME during the nap (lights off, house
     armed, Sleep Focus). Before that edit, a daytime nap was outside every window and got nothing.
     The integration knows a nap is on: `nap_alarm_times` from the app, and the napping helper.
   - **Fix:** while a nap is on (nap alarms set, from *Nap started* until *Nap ended*),
     `bedtime_pending` is off (attribute `paused: nap`), so neither the nudge nor the automatic
     report fires; the report also checks for a nap itself. When the nap ends, pending is on again
     if it still applies.
   - **The nap that turns into the night** (Michael's case: you nap, don't get up, and it's
     bedtime): when the nap ends (its last alarm stopped, or End nap) and you're still in bed with
     bedtime pending, the nudge won't see it, because it starts on getting into bed and you never
     left. **To decide:**
     a. **Bedtime by itself:** still in bed 10 min after the nap ended → Home Assistant sends
        RUN_BEDTIME, as the nudge would (only inside the bedtime windows? or any time pending is on).
     b. **Ask first:** "Still in bed after your nap. Start bedtime?" with Start bedtime / Not yet;
        no answer in 10 min → bedtime starts (or doesn't).
     c. **Nothing automatic:** the bar offers Good night (it's already there with alarms set), and
        the automatic report notes it.
   - The nap's own end (Nap End - App, the napping helper off) happens first either way.
